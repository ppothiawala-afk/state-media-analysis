State Media Coverage Tracker

Topic coverage across state-level news feeds — counts, not sentiment.
How to read this. The primary measure is topic share — the fraction of a source's output about each topic — not raw article counts, so a prolific outlet doesn't masquerade as a hot topic. Sources are a specific set of nonprofit state newsrooms (see “Source composition” below), not a state's entire media landscape. No sentiment or tone is inferred anywhere.
